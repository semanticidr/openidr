# Open IDR
OpenIDR is an open-source, headless incident investigation server for logs.

It continuously collects logs from configured sources and makes them available for on-demand investigation through gRPC and MCP. Investigations can be triggered by a human, an alert, a script, an AI agent, or any external system that can call the API.

OpenIDR uses the collected log evidence to generate structured root-cause analysis reports with citations back to the underlying logs.
